# CORD CICO BIZ — Android Test Build

This package is a testable Android project for CORD CICO BIZ.

Important:
- This is a development/test project, not a signed production APK.
- To create the APK, install the project dependencies and run an Android build with Expo/EAS.
- Supabase credentials are required for cloud features.
- The current project includes a simple test dashboard and local test storage so the app can be opened and tested before backend configuration.
